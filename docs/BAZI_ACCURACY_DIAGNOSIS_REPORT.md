# 八字命理系统准确性诊断报告

> 生成日期：2026-05-08  
> 诊断范围：排盘 / 十神 / 大运 / 旺衰格局 / Prompt / AI 解释层  
> 测试结果：51 项全通过

---

## 一、结论

| 维度 | 风险等级 | 说明 |
|------|---------|------|
| 排盘准确性 | **低** | 委托 lunar_python，立春/节气/农历/子时均正确 |
| 十神映射 | **低** | 程序规则层完整实现，不依赖 AI |
| 大运流年 | **低** | lunar_python 内部处理顺逆/起运/边界 |
| 旺衰格局判断 | **中→低**（已修复） | 之前完全交 AI 自由发挥 → 现在有规则引擎兜底 |
| AI 幻觉控制 | **中→低**（已修复） | 之前 AI 自算十神/改大运/乱说本命年 → 现在注入速查表+硬约束 |
| Prompt 工程 | **中→低**（已修复） | 之前存在伪占位符/无版本/无变量校验 → 现在已加固 |

**最大问题（已修复）**：旺衰/格局/喜用神完全由 AI 自由推断，缺乏程序规则兜底，导致每次分析结果飘忽不定。

## 二、系统链路

```
用户输入（出生日期/时间/历法/性别/经度）
  → 日期标准化 (_parse_ymd, _parse_hm)
  → 农历↔阳历转换 (Lunar.fromYmdHms / solar.getLunar)
  → 经度真太阳时近似 (_to_solar: ±offset_min)
  → lunar_python 排盘 (lunar.getEightChar)
  → 四柱提取 (year/month/day/hour stems & branches)
  → 五行统计 (天干+地支本气)
  → 十神/藏干/纳音/地势/旬空 (_enrich_chart)
  → 大运/流年 (getYun → getDaYun / 流年干支)
  → 生肖/十神速查表 (build_shishen_table)
  → 【新增】规则引擎 (bazi_rules.analyze_chart)
      ├── calculate_strength → 旺衰评分
      ├── analyze_pattern → 格局判断
      └── infer_useful_gods → 喜用忌神
  → Prompt 渲染 (render_subject_block + _format_rule_analysis)
  → AI 解释层 (deepseek-v4-pro, temperature=0.5)
  → 安全输出层 (append_disclaimer, 不重复)
```

## 三、P0 问题（已修复）

| # | 问题 | 原因 | 修复 |
|---|------|------|------|
| 1 | AI 自行推算十神关系导致错误（如"丙=劫财"） | Prompt 未提供速查表 | 注入十神速查表 + 硬约束 |
| 2 | AI 把非本命年说成本命年 | 无生肖信息注入 | 注入生肖 + 本命年定义 |
| 3 | AI 更改大运干支 | 无约束 | 大运标记 ◀ 当前 + 硬约束 |

| 5 | Prompt 伪占位符 `{丙对应十神}` | 未做变量校验 | 加 _render 警告 + 移除伪占位 |
| 6 | 报告生成用旧缓存数据 | report_service 读 DB | 改为现算 enriched chart |
| 7 | 输出截断 | max_tokens=1024 | 提升至 4096 |

## 五、当前准确性边界

### 能保证的：
- 四柱排盘正确（立春换年、节气换月、子时处理）
- 十神映射 100% 正确（程序计算，不依赖 AI）
- 大运排列正确（顺逆、起运年龄、当前标记）
- 流年干支正确
- 基础旺衰评估（得令/失令、得地、得助）方向正确
- 基础格局取法（月令本气透干/不透）方向正确
- AI 不再自行修改排盘事实

### 不能保证的：
- 复杂格局（合冲化格/从格/杂气格）的精确判断
- 旺衰评分在接近 50 分（平衡区）时的精确判断
- AI 解释层的专业深度（取决于 LLM 能力）
- 合冲刑害对格局的破坏程度量化
