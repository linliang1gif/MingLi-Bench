# 命理评测平台功能清单

## 版本信息

当前版本：V1.4.0
版本定位：自用稳定版 / 阴宅与天星术研究版
运行方式：本地运行
数据库：SQLite
数据库路径：backend/storage/mingli.db

---

## 一、命理分析

### 1. AI 问命

围绕命主档案、命盘信息和上下文进行对话分析。

支持：

- 命主上下文读取
- 命盘信息辅助问答
- 普通问答
- 流式对话
- 风险词审核

### 2. 命主档案

用于创建和维护命主基础资料。

支持：

- 创建命主
- 查看命主
- 删除命主
- 关联命盘分析
- 关联历史记录

### 3. 命盘分析

用于计算和展示八字相关信息。

支持：

- 八字排盘
- 五行分析
- 十神分析
- 大运分析
- 流年分析
- 命盘结构化展示

### 4. 分析报告

用于生成不同类型的命理报告。

支持：

- 综合报告
- 财运报告
- 事业报告
- 感情报告
- 流年报告
- AI 生成报告
- 风险词审核

### 5. 报告版本

用于查看报告详情和历史版本快照。

支持：

- 报告详情
- 历史版本
- Prompt 版本
- 模型信息
- 风控结果
- 古籍引用来源
- references_json 版本保存
- Markdown 复制
- Markdown 下载

### 6. 历史记录

用于查看命主相关对话与历史内容。

支持：

- 对话历史
- 报告历史
- 命主关联历史

### 7. 案例审核

用于标准案例反馈、审核和统计。

支持：

- 案例查看
- 反馈提交
- 反馈统计
- 案例审核
- 后续用于优化 Prompt 和规则

## 二、风水工具

### 1. 房屋档案

用于记录住宅、办公室、店铺等空间信息。

支持：

- 新建房屋档案
- 查看房屋详情
- 记录房屋类型
- 记录建成年份
- 记录入住时间
- 记录主门朝向
- 关联罗盘测点
- 关联风水报告

### 2. 罗盘测向

用于记录角度、八方、二十四山和测量场景。

支持：

- 手动输入角度
- H5 真实测向
- 八方识别
- 二十四山识别
- 测点保存
- 测点删除
- 大门、床头、灶台、书桌等场景记录
- 从大门测点同步主门朝向

### 3. 阳宅基础报告

基于房屋档案和测向记录生成基础风水说明。

支持：

- 读取房屋档案
- 读取罗盘测点
- 分析大门朝向
- 分析已测点位
- 输出基础阳宅建议
- 输出现代居住环境建议
- 写入 reports
- 写入 report_versions
- 风险词审核

### 4. 玄空飞星

用于判断三元九运、二十四山坐向，生成简化九宫飞星基础盘，并生成玄空飞星报告。

支持：

- 三元九运判断
- 房屋元运判断
- 二十四山向首识别
- 坐山反推
- 简化九宫飞星基础盘
- 九宫格展示
- 玄空飞星报告生成
- 写入 report_versions
- 报告中心筛选
- 风险词审核

### 5. 拍照识别

用于手机拍照或上传房间图片，识别房间对象，允许用户校正，并生成拍照风水报告。

支持：

- 选择房屋档案
- 选择房间类型
- 手机拍照
- 图片上传
- 图片预览
- AI 图片对象识别
- 无多模态能力时返回可校正 mock 结构
- 用户校正床、门、窗、镜子、横梁等关键对象
- 填写床头方向和补充说明
- 生成拍照风水报告
- 写入 reports
- 写入 report_versions
- 报告中心筛选
- 删除拍照识别记录并尽量删除图片文件
- 风险词审核

## 五、安全边界

本系统为自用传统文化与命理分析工具，不作为医疗、法律、投资或重大人生决策依据。

安全原则：

1. 不返回 API Key 原文。
2. 不输出医疗诊断。
3. 不输出法律结论。
4. 不输出投资承诺。
5. 不输出生死强断。
6. 不输出恐吓性判断。
7. 不诱导消费化解。
8. 不承诺改命、发财、复合、消灾。
9. 风险词用于降低恐吓、强断、诱导消费和绝对化表达。
10. 数据库备份只写入 backend/storage 目录。
